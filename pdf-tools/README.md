# เครื่องมือ PDF (PDF Toolbox)

เว็บแอปรวมเครื่องมือจัดการไฟล์ **PDF / รูปภาพ / วิดีโอ** ทั้งหมด 15 รายการ
ทุกอย่างประมวลผลด้วย JavaScript ในเบราว์เซอร์ของผู้ใช้เอง — **ไม่มีการอัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์**
และเมื่อเปิดครบหนึ่งครั้งแล้วยังใช้งานแบบออฟไลน์ได้ (ติดตั้งเป็นแอปบนมือถือได้ผ่าน PWA)

เปิดใช้งานที่ `<ที่อยู่เว็บไซต์>/pdf-tools/`

## เครื่องมือทั้งหมด

| กลุ่ม | เครื่องมือ | สิ่งที่ทำได้ |
| --- | --- | --- |
| PDF | รวมไฟล์ PDF | ต่อหลายไฟล์ตามลำดับที่จัด |
| PDF | จัดหน้า PDF | ลากสลับลำดับ หมุน ลบหน้า (ลากได้ทั้งเมาส์และนิ้ว) |
| PDF | แยกไฟล์ PDF | ดึงหน้าที่เลือก / แยกทีละหน้า / แบ่งทุก N หน้า (ได้ ZIP) |
| PDF | ลดขนาด PDF | โหมดเร็ว (คงข้อความ) และโหมดแปลงเป็นภาพ + ตัวเลือกขาวดำ |
| PDF | PDF → JPG/PNG | เลือก dpi และช่วงหน้า หลายหน้ารวมเป็น ZIP |
| PDF | ใส่เลขหน้า | 6 ตำแหน่ง 5 รูปแบบ (รองรับข้อความไทย) ข้ามหน้าปกได้ |
| PDF | ใส่ลายน้ำ | ข้อความไทย/อังกฤษ หรือรูปโลโก้ วางกลาง/เรียงเต็มหน้า/มุมล่าง |
| PDF | หมุนหน้า | ทุกหน้า / หน้าคี่ / หน้าคู่ / ระบุหน้า |
| PDF | ดึงข้อความ | ดึงข้อความเป็น .txt พร้อมปุ่มคัดลอก |
| PDF | ลงลายเซ็น | วาดลายเซ็นด้วยนิ้วหรือใช้รูป แล้วลากวางตำแหน่งบนหน้า |
| รูปภาพ | สแกนเอกสาร | ถ่ายรูป → ฟิลเตอร์เอกสาร (auto level / ขาวดำ adaptive threshold) → PDF |
| รูปภาพ | JPG → PDF | รวมรูปหลายไฟล์เป็น PDF เลือกขนาดกระดาษ/ขอบ |
| รูปภาพ | ลดขนาดไฟล์ภาพ | ย่อ + บีบอัด JPG/PNG/WEBP หลายไฟล์พร้อมกัน |
| วิดีโอ | **ลดขนาดวิดีโอ** | ย่อความละเอียด ปรับ bitrate/fps ตัดช่วง เก็บหรือตัดเสียง |
| วิดีโอ | แคปภาพจากวิดีโอ | ดึงภาพนิ่งทุก ๆ N วินาที หรือระบุวินาที |

## การลดขนาดวิดีโอทำงานอย่างไร

1. **WebCodecs (ทางหลัก)** — ถอดรหัสเฟรมผ่าน `requestVideoFrameCallback`
   เข้ารหัสใหม่เป็น **H.264** ด้วย `VideoEncoder` เสียงถอดด้วย `decodeAudioData`
   แล้วเข้ารหัสเป็น **AAC** ด้วย `AudioEncoder` จากนั้นรวมเป็นไฟล์ **MP4** ด้วย `mp4-muxer`
   (ใช้ได้บน Chrome / Edge / Android Chrome รุ่นใหม่ และเร็วกว่าเรียลไทม์ได้)
2. **MediaRecorder (ทางสำรอง)** — สำหรับเบราว์เซอร์ที่ยังไม่มี WebCodecs
   วาดเฟรมลง canvas แล้วบันทึกสตรีมแบบเรียลไทม์ (ได้ WebM หรือ MP4 แล้วแต่เบราว์เซอร์)
   เสียงส่งผ่าน Web Audio ไปยัง `MediaStreamDestination` จึงไม่ดังออกลำโพงระหว่างประมวลผล

Bitrate คำนวณจาก `กว้าง × สูง × fps × bits-per-pixel` ตามระดับคุณภาพที่เลือก
(สูง 0.115 / กลาง 0.07 / ประหยัด 0.045 / เล็กที่สุด 0.028) และแสดงขนาดโดยประมาณให้ก่อนกดทำงาน

## โครงสร้างไฟล์

```
pdf-tools/
├── index.html              โครงหน้าเว็บ + แถบแท็บล่าง
├── manifest.webmanifest    ข้อมูล PWA
├── sw.js                   service worker (ใช้งานออฟไลน์)
├── assets/
│   ├── css/app.css         ธีมสว่าง/มืด, การ์ดเครื่องมือ, ตัวควบคุมต่าง ๆ
│   ├── fonts/              ฟอนต์ Sarabun (ใช้ทั้ง UI และฝังลง PDF ภาษาไทย)
│   └── js/
│       ├── core.js         ไอคอน, โหลดไลบรารีแบบ lazy, ตั้งค่า, ไฟล์ล่าสุด (IndexedDB)
│       ├── ui.js           ชุด UI: dropzone, chips, slider, toggle, runner, drag reorder
│       ├── app.js          router + หน้าแรก/ล่าสุด/ตั้งค่า
│       ├── tools-pdf.js    เครื่องมือ PDF 10 รายการ
│       ├── tools-image.js  สแกน / รูป→PDF / ลดขนาดภาพ
│       └── tools-video.js  ลดขนาดวิดีโอ / แคปภาพจากวิดีโอ
└── vendor/                 ไลบรารีโอเพนซอร์ส (โหลดจากเครื่อง ไม่พึ่ง CDN)
```

## หมายเหตุการใช้งาน

- ไฟล์ใหญ่มาก ๆ ถูกจำกัดด้วยหน่วยความจำของเครื่อง (มือถือรุ่นเก่าอาจไม่ไหวกับวิดีโอยาว)
- ระหว่างบีบอัดวิดีโอ ห้ามสลับแอปหรือปิดหน้าจอ เพราะเบราว์เซอร์จะพักการทำงานเบื้องหลัง
- โหมด "ลดขนาด PDF" แบบแปลงเป็นภาพจะทำให้ข้อความกลายเป็นภาพ (ค้นหาข้อความไม่ได้)
- "ไฟล์ล่าสุด" เก็บไว้ใน IndexedDB ของเบราว์เซอร์เท่านั้น สูงสุด 24 ไฟล์
