TESLA SECOND SCREEN

เลือกว่าเครื่องนี้คือเครื่องไหน

ทำงานแบบ WebRTC ต่อตรงระหว่างสองเครื่อง ภาพไม่วิ่งผ่านเซิร์ฟเวอร์ใคร (ใช้เซิร์ฟเวอร์กลางแค่ตอนจับคู่รหัสเท่านั้น)

ก่อนใช้ครั้งแรก

1. จอด/จอดชาร์จก่อน — เบราว์เซอร์ของ Tesla ใช้ได้เต็มที่ตอนรถจอด
2. ให้รถกับโน้ตบุ๊ก อยู่วง Wi-Fi เดียวกัน (ต่อรถเข้า hotspot ของโน้ตบุ๊ก/มือถือได้) ภาพจะวิ่งตรงในวง LAN คมและหน่วงต่ำสุด ถ้าอยู่คนละเน็ตต้องมี TURN server เอง
3. อยากได้ "จอที่สองจริง ๆ" (ลากหน้าต่างข้ามไปได้ ไม่ใช่ mirror) ต้องลง virtual display driver ที่โน้ตบุ๊กก่อน แล้วค่อยแชร์จอเสมือนนั้นมา — อ่านราย ละเอียดใน README ของโปรเจกต์
4. ยังไม่แน่ใจว่าเบราว์เซอร์รถไหว → กด "ตรวจเบราว์เซอร์" บนจอรถก่อน
