# Shopee Order Report: สรุปรายจ่าย Shopee รายเดือน

โปรแกรมนี้เปิดเบราว์เซอร์ให้คุณ login Shopee เอง แล้วไล่ดูประวัติการสั่งซื้อทั้งหมด จากนั้นทำรายงานให้

- **รายการของที่ซื้อแยกตามเดือน** พร้อมยอดรวมของแต่ละเดือน
- **จัดกลุ่มคำสั่งซื้อที่จ่ายพร้อมกัน** (checkout เดียวกัน แม้จะมาจากหลายร้าน) และแสดงยอดรวมของกลุ่ม
  - ป้าย `จ่ายพร้อมกัน`: Shopee ระบุ checkout id มาให้ จึงแน่นอน
  - ป้าย `น่าจะจ่ายพร้อมกัน`: ไม่มี checkout id จึงเดาจากเวลาสั่งที่ห่างกันไม่เกิน 2 นาที และจ่ายด้วยวิธีเดียวกัน
- **วิธีชำระเงิน** (บัตรเครดิต, ShopeePay, SPayLater, เก็บเงินปลายทาง ฯลฯ)
- **บัตรที่ใช้จ่าย** เช่น `VISA *1234`
- ยอดแยกตามวิธีจ่ายหรือตามบัตรของแต่ละเดือน
- ไม่นับคำสั่งซื้อที่ถูกยกเลิก (ยังแสดงในรายงานเป็นสีจาง)

> **เรื่องเลขบัตร:** Shopee ไม่เคยแสดงเลขบัตรเต็ม และระบบนี้ก็ไม่มีทางได้เลขเต็ม เพราะ Shopee เองก็ไม่ส่งมาให้ สิ่งที่ได้คือ 4 หลักท้ายกับประเภทบัตร (ถ้าหน้าคำสั่งซื้อแสดงไว้) ซึ่งเพียงพอให้รู้ว่าจ่ายด้วยบัตรใบไหน

## แบบง่ายที่สุด: ปุ่มบุ๊กมาร์ก (ไม่ต้องติดตั้งอะไร)

เปิดไฟล์ `web/dist/index.html` แล้วลากปุ่ม "ดึงรายจ่าย Shopee" ไปวางที่แถบบุ๊กมาร์ก จากนั้น login ที่ shopee.co.th แล้วกดบุ๊กมาร์กนั้น
รายงานจะขึ้นบนหน้า Shopee เลย และมีปุ่มดาวน์โหลดรายงานกับไฟล์ CSV ให้

- โค้ดอยู่ที่ `web/bookmarklet.js` ใช้โค้ดแปลงข้อมูลชุดเดียวกับโปรแกรมด้านล่าง (`core.js`)
- ถ้าแก้โค้ด ให้รัน `npm run build` เพื่อสร้าง `web/dist/` ใหม่

## แบบโปรแกรม (Node.js): ติดตั้งครั้งแรกครั้งเดียว

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป แล้วรันในโฟลเดอร์นี้:

```bash
npm install
```

```bash
npx playwright install chromium
```

(ถ้าเครื่องมี Google Chrome อยู่แล้ว โปรแกรมจะใช้ Chrome ก่อน เพราะ Shopee ไม่ค่อยขึ้น captcha กับ Chrome จริง)

## ใช้งาน

```bash
node shopee-report.js
```

1. หน้าต่างเบราว์เซอร์จะเปิดขึ้นมา **login Shopee ตามปกติในหน้าต่างนั้น** (ใส่รหัส/OTP/ยืนยันตัวตนเอง) โปรแกรมจะรอแล้วทำงานต่อเองเมื่อ login เสร็จ
2. โปรแกรมจะเลื่อนดูหน้า "การซื้อของฉัน" จนสุด แล้วเปิดหน้ารายละเอียดของทีละคำสั่งซื้อ (ประมาณ 2–4 วินาทีต่อคำสั่งซื้อ)
3. เสร็จแล้วเปิดไฟล์ `output/report.html` ดูได้เลย

ไฟล์ที่ได้ในโฟลเดอร์ `output/`:

| ไฟล์ | เนื้อหา |
|---|---|
| `report.html` | รายงานรายเดือนแบบสวยงาม เปิดในเบราว์เซอร์ |
| `orders.csv` | 1 แถวต่อ 1 คำสั่งซื้อ: เดือน, กลุ่มจ่ายพร้อมกัน, เวลา, ร้าน, สินค้า, ยอด, ยอดรวมกลุ่ม, วิธีจ่าย, บัตร |
| `items.csv` | 1 แถวต่อ 1 สินค้า |
| `monthly.csv` | ยอดรวมรายเดือน และแยกตามวิธีจ่าย |

ไฟล์ CSV เปิดด้วย Excel หรือ Google Sheets ได้ ภาษาไทยไม่เพี้ยน

### ตัวเลือกที่ใช้บ่อย

```bash
node shopee-report.js --since 2025-01
```
ดึงเฉพาะตั้งแต่ ม.ค. 2025 เป็นต้นไป (เร็วขึ้นมากถ้ามีประวัติเยอะ)

```bash
node shopee-report.js --report-only
```
สร้างรายงานใหม่จากข้อมูลที่ดึงไว้แล้ว โดยไม่ต้องเปิดเบราว์เซอร์

```bash
node shopee-report.js --max-orders 5
```
ลองดึงแค่ 5 คำสั่งซื้อเพื่อทดสอบก่อน

- `--include-cancelled` นับคำสั่งซื้อที่ยกเลิกรวมในยอดด้วย
- `--group-window 300` ปรับเวลาที่ใช้เดาว่า "จ่ายพร้อมกัน" (วินาที)
- `--refresh` ดึงรายละเอียดใหม่ทั้งหมด แม้จะเคยดึงไว้แล้ว
- `--help` ดูตัวเลือกทั้งหมด

การรันครั้งถัดไปจะเร็วขึ้น เพราะโปรแกรมจำ login ไว้ใน `.shopee-profile/` และจะดึงเฉพาะคำสั่งซื้อใหม่ที่ยังไม่เคยดึง

## ความปลอดภัย

- โปรแกรม **ไม่เคยเห็นรหัสผ่าน** เพราะคุณพิมพ์ในหน้าเว็บของ Shopee เอง
- ข้อมูลทั้งหมดอยู่ในเครื่องคุณเท่านั้น ไม่ได้ส่งไปที่อื่น
- โฟลเดอร์ `.shopee-profile/` มี session ที่ login ไว้ อย่าแชร์หรือ commit ขึ้น git (มี `.gitignore` กันไว้แล้ว) ถ้าจะ logout ให้ลบโฟลเดอร์นี้ทิ้ง
- `output/` มีข้อมูลการซื้อ ที่อยู่ และเบอร์โทร (แบบปิดบางส่วน) ของคุณ ควรเก็บไว้เป็นความลับ

## ถ้าข้อมูลบางช่องว่าง

Shopee ไม่มี API สาธารณะสำหรับประวัติการซื้อ โปรแกรมจึงอ่านข้อมูลจากสิ่งที่หน้าเว็บ Shopee โหลดมาแสดงเอง ทั้ง JSON ภายในของ Shopee และข้อความบนหน้าคำสั่งซื้อ ถ้า Shopee เปลี่ยนหน้าเว็บ บางช่องอาจหาไม่เจอ (เช่น วิธีจ่ายขึ้นว่า "ไม่ทราบ")

ข้อมูลดิบของทุกคำสั่งซื้อเก็บไว้ที่ `output/raw/details/<order_id>.json` และ `.txt` ถ้าเจอปัญหา ให้ส่งไฟล์ของคำสั่งซื้อที่มีปัญหามาดู (**ลบชื่อ ที่อยู่ และเบอร์โทรออกก่อน**) จะได้แก้ให้อ่านได้ถูก แก้แล้วรัน `--report-only` ได้เลย ไม่ต้องดึงข้อมูลใหม่
